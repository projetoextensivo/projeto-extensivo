# DentalCare Backend

Estrutura inicial da API do sistema DentalCare, desenvolvida com Java 21, Spring Boot e Swagger/OpenAPI.

## Requisitos

- JDK 21 ou superior
- Maven 3.9 ou superior

## Executar

Na pasta `backend`, execute:

```bash
mvn spring-boot:run
```

Após iniciar a aplicação, a documentação Swagger UI estará disponível em `http://localhost:8080/swagger-ui.html` e o documento OpenAPI em `http://localhost:8080/api-docs`.
